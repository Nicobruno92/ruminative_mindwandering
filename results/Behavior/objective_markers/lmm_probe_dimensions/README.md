### The two datasets

| Dataset | Pre-probe window | Note |
|---|---|---|
| `full_segment` | Whole block before the probe (15–40 trials, median 30) | Main analysis |
| `n10` | Last 10 trials before the probe | Sharper temporal locality, much noisier estimates |

In `n10` there are only 0–1 no-go trials per probe, so `commission_rate` is
binary and 847 of 2460 probes drop out of that model (n = 1613). This is
handled correctly by the binomial formulation, not by imputation.

## What is in each track

**`glmm/` — the primary result.** Binomial (logit) for the three rate markers,
Gamma (log) for `rtcv`. Read this one unless you have a reason not to.

**`sensitivity_olre/`** — the *same* binomial model with an extra random effect
per observation, `(1|subject) + (1|obs_id)`. It is not a different family; it
relaxes the binomial's assumption that variance is exactly `n·p·(1−p)`. Compare
against `glmm/` whenever the dispersion statistic is well above 1. Only the
three binomial markers appear here — `rtcv` is Gamma, which already carries its
own dispersion parameter.

**`sensitivity_gaussian/`** — the original Gaussian LMM, kept so the effect of
the respecification is visible rather than assumed. Also the only track
containing `total_errors_legacy` (the old sum-of-two-rates definition).

**`sensitivity_transformed/`** — Gaussian LMM on a transformed response:
`log(rtcv)`, and Haldane-corrected empirical logit for the rates.

### Files inside each track

| File | Contents |
|---|---|
| `<marker>_lmm_results.csv` | One row per fixed effect: `estimate`, `std_error`, `z_value`, `p_value`, `conf_lower/upper`, `p_fdr`, `significant_fdr`, plus `converged`, `singular`, `re_sd`, `max_grad`, `dispersion`, `n_obs` |
| `lmm_summary_all_markers.csv` | All markers stacked, with readable labels |
| `moderation_summary.csv` | `onoff × moderator` interaction per marker, FDR-corrected across all marker × moderator tests |
| `<marker>_combined_forest.png` | Additive effects + moderation, side by side |
| `<marker>_scatter_grid.{html,png,svg}` | One binscatter panel per predictor |
| `<marker>_combined_panel.png` | Scatter grid + forest in one figure |
| `interaction_<marker>_<mod>.png` | Interaction plot for significant moderator pairs |
| `predictor_standardization.csv` | The SDs used to z-score predictors |

**Reading the coefficients.** `estimate` is on the **link scale** — log-odds
for binomial, log for Gamma. A binomial β of −0.49 means the log-odds of an
omission fall by 0.49 per SD of `onoff`. It is not a change in rate. The column
is named `t_value` for compatibility with the plotting code, but the statistic
is a Wald **z**; `z_value` holds the same number under its honest name.

**Reading the intercept.** For a GLMM with a random intercept this is the
*conditional* (median-subject) value, not the marginal mean. For
`omission_rate` it is −4.20 → 1.47 %, which matches the median subject's rate
(1.51 %), not the pooled mean (3.83 %). This is expected, not a bug.

## Convergence and fit quality

Every results CSV carries its own fit-quality columns. Check these before
trusting a row:

| Column | Meaning |
|---|---|
| `converged` | No optimizer warning from `lme4` |
| `singular` | `isSingular()` — a random-effect variance collapsed to ~0. A singular fit can converge and still be untrustworthy, so check this too |
| `re_sd` | SD of each random effect, e.g. `subject=0.83; obs_id=0.51` |
| `max_grad` | Max absolute gradient at the optimum; should be small |
| `dispersion` | Pearson χ²/df. Near 1 = binomial assumption OK. Well above 1 = overdispersed, so prefer `sensitivity_olre/` |

Non-converged and singular models are **reported, never silently dropped**.

## `model_comparison.csv`

The central transparency artefact: one row per marker × predictor, with
`estimate__`, `p_fdr__` and `significant_fdr__` columns for each of the four
tracks. Use it to state whether a conclusion is robust to specification — or to
show exactly where it is not.

A disagreement between `glmm` and `sensitivity_olre` almost always means the
plain binomial underestimated the standard error. In that case the β barely
moves while the SE roughly doubles, and the effect should not be claimed.

## `diagnostics/`

One `<track>_<marker>_diagnostics.png` and one
`<track>_<marker>_residual_summary.csv` per fitted model. Each figure has three
panels: normal Q-Q, residuals vs fitted, and **binned residuals** (Gelman &
Hill) with a ±2 SE band. Binned residuals are used because raw residuals from a
binomial model are uninformative against fitted values when the response is
discrete; `DHARMa` is unavailable on this network.

The summary CSVs carry `skew`, `kurtosis`, `breusch_pagan_stat/p` and `n`.
Normality is reported descriptively rather than as a pass/fail test: at
n ≈ 2460 Shapiro-Wilk rejects on trivial deviations.

This directory is the reason the respecification happened — the original
pipeline validated no assumption at all.
