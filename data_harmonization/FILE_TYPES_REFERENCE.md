# EEG Preprocessing Pipeline - File Types Reference

## Overview
This document lists all file types generated by the preprocessing pipeline from raw data to final preprocessed epochs, with their exact BIDS naming conventions.

## File Naming Convention
All files follow BIDS format: `sub-{ID}_task-{session}_desc-{description}_{suffix}.{extension}`

---

## 1. RAW DATA FILES (BIDS/raw)

### BrainVision Raw Files
**Location**: `/BIDS/raw/sub-{ID}/eeg/`

- **Header**: `sub-{ID}_task-{session}_eeg.vhdr`
- **Data**: `sub-{ID}_task-{session}_eeg.eeg`
- **Markers**: `sub-{ID}_task-{session}_eeg.vmrk`
- **Sidecar**: `sub-{ID}_task-{session}_eeg.json`
- **Channels**: `sub-{ID}_task-{session}_channels.tsv`

**Description**: Original unprocessed EEG data in BrainVision format

**View with**:
```python
DATA_PATH = "/Volumes/cenir/analyse/meeg/CYBERSART/BIDS/raw"
FILE_TYPE = "raw"
```

---

## 2. PREPROCESSED RAW FILES (derivatives)

### ICA-Cleaned Raw Data
**Location**: `/BIDS/derivatives/sub-{ID}/eeg/`

- **File**: `sub-{ID}_task-{session}_desc-icaClean_eeg.fif`
- **Sidecar**: `sub-{ID}_task-{session}_desc-icaClean_eeg.json`
- **Channels**: `sub-{ID}_task-{session}_desc-icaClean_channels.tsv`

**Description**: Continuous EEG data after:
- Notch filtering (50, 100, 150 Hz)
- Bad channel detection and interpolation
- ICA artifact removal (ocular, muscle)
- Average reference
- Filtering (0.1-45 Hz)

**Config reference**: `names.raw_clean_desc: "icaClean"`

**View with**:
```python
DATA_PATH = "/Volumes/cenir/analyse/meeg/CYBERSART/BIDS/derivatives"
FILE_TYPE = "raw"
```

### CSD-Transformed Raw Data (Optional)
**Location**: `/BIDS/derivatives/sub-{ID}/eeg/`

- **File**: `sub-{ID}_task-{session}_desc-csd_eeg.fif`
- **Sidecar**: `sub-{ID}_task-{session}_desc-csd_eeg.json`
- **Channels**: `sub-{ID}_task-{session}_desc-csd_channels.tsv`

**Description**: Current Source Density transformation applied to ICA-cleaned data
- Computed on artifact-removed data
- Used for spatial analysis
- Only created if `use_csd: true` in config

**Config reference**: `names.csd_desc: "csd"`, `use_csd: false` (default)

**View with**:
```python
DATA_PATH = "/Volumes/cenir/analyse/meeg/CYBERSART/BIDS/derivatives"
FILE_TYPE = "raw"
```

---

## 3. ICA DECOMPOSITION FILES (derivatives)

### ICA Object
**Location**: `/BIDS/derivatives/sub-{ID}/eeg/`

- **File**: `sub-{ID}_task-{session}_desc-ica_ica.fif`
- **Sidecar**: `sub-{ID}_task-{session}_desc-ica_ica.json`

**Description**: ICA decomposition object containing:
- Independent components
- Mixing matrix
- Excluded component indices
- ICLabel classifications

**Config reference**: `names.ica_desc: "ica"`

**ICA Parameters** (from config.yaml):
```yaml
ica:
  method: picard
  n_components: 30
  max_iter: 1000
  random_state: 42
```

**View with**:
```python
DATA_PATH = "/Volumes/cenir/analyse/meeg/CYBERSART/BIDS/derivatives"
FILE_TYPE = "ica"
```

**Note**: ICA plotting requires raw data for source visualization

---

## 4. EPOCH FILES (derivatives)

### Evoked Epochs
**Location**: `/BIDS/derivatives/sub-{ID}/eeg/`

- **File**: `sub-{ID}_task-{session}_desc-evoked_epo.fif`
- **Sidecar**: `sub-{ID}_task-{session}_desc-evoked_epo.json`
- **Channels**: `sub-{ID}_task-{session}_desc-evoked_channels.tsv`

**Description**: Event-related epochs time-locked to stimuli
- Time window: -0.2 to 1.0 s relative to stimulus
- Baseline correction: -0.2 to 0 s
- Events: go/correct, nogo/correct
- After AutoReject artifact rejection

**Config reference**: `names.evoked_desc: "evoked"`

**Epoch Parameters** (from config.yaml):
```yaml
epochs_evoked:
  tmin: -0.2
  tmax: 1.0
  baseline: [-0.2, 0]
evoked_filter_go_nogo_only: true
```

**View with**:
```python
DATA_PATH = "/Volumes/cenir/analyse/meeg/CYBERSART/BIDS/derivatives"
FILE_TYPE = "epochs"
EPOCH_TYPE = "evoked"
```

### State Epochs
**Location**: `/BIDS/derivatives/sub-{ID}/eeg/`

- **File**: `sub-{ID}_task-{session}_desc-state_epo.fif`
- **Sidecar**: `sub-{ID}_task-{session}_desc-state_epo.json`
- **Channels**: `sub-{ID}_task-{session}_desc-state_channels.tsv`

**Description**: Pre-probe mini-epochs for mind-wandering state analysis
- 2-second mini-epochs from 10 seconds before thought probe
- Overlapping windows (1 second overlap)
- After AutoReject artifact rejection

**Config reference**: `names.state_desc: "state"`

**State Parameters** (from config.yaml):
```yaml
state_windows:
  pre_probe_s: 10
  mini_epoch_s: 2
  exclude_last_s_before_resp: 0
state_windows_overlap_s: 1.0
```

**View with**:
```python
DATA_PATH = "/Volumes/cenir/analyse/meeg/CYBERSART/BIDS/derivatives"
FILE_TYPE = "epochs"
EPOCH_TYPE = "state"
```

## 5. QUALITY ASSESSMENT FILES

### HTML Report
**Location**: `/BIDS/derivatives/sub-{ID}/reports/`

- **File**: `sub-{ID}_task-{session}_desc-autoPreproc_eeg.html`

**Description**: Comprehensive preprocessing report including:
- PSD before/after filtering
- Bad channels detected
- ICA components and exclusions
- Epoch rejection statistics
- Quality metrics

### Preprocessing Log
**Location**: `/BIDS/derivatives/`

- **File**: `logs_preprocessing_details_all_subjects_eeg.json`

**Description**: JSON log with detailed metrics for all subjects/sessions

## Preprocessing Pipeline Flow

```
1. RAW BRAINVISION (.vhdr, .eeg, .vmrk)
   ↓
2. Notch filter (50, 100, 150 Hz)
   ↓
3. [Optional] ASR artifact removal
   ↓
4. Bad channel detection (PyPREP RANSAC)
   ↓
5. Interpolate bad channels
   ↓
6. Set montage + average reference
   ↓
7. Filter (0.1-45 Hz)
   ↓
8. ICA fitting and component removal
   ↓
9. SAVE: desc-icaClean_eeg.fif (cleaned raw)
   ↓
10. [Optional] CSD transformation
    ↓
11. SAVE: desc-csd_eeg.fif (CSD raw)
    ↓
12. Extract evoked epochs (-0.2 to 1.0 s)
    ↓
13. AutoReject artifact rejection
    ↓
14. SAVE: desc-evoked_epo.fif (evoked epochs)
    ↓
15. Extract state epochs (2s windows, 10s pre-probe)
    ↓
16. AutoReject artifact rejection
    ↓
17. SAVE: desc-state_epo.fif (state epochs)
```

## Quick Reference Table

| Stage | File Pattern | Suffix | Description |
|-------|-------------|--------|-------------|
| Raw | `sub-{ID}_task-{session}_eeg.vhdr` | N/A | Original BrainVision |
| ICA-cleaned | `sub-{ID}_task-{session}_desc-icaClean_eeg.fif` | `_eeg.fif` | Cleaned continuous |
| CSD | `sub-{ID}_task-{session}_desc-csd_eeg.fif` | `_eeg.fif` | CSD-transformed |
| ICA object | `sub-{ID}_task-{session}_desc-ica_ica.fif` | `_ica.fif` | ICA decomposition |
| Evoked epochs | `sub-{ID}_task-{session}_desc-evoked_epo.fif` | `_epo.fif` | Event-related |
| State epochs | `sub-{ID}_task-{session}_desc-state_epo.fif` | `_epo.fif` | Pre-probe windows |

## Using view_preprocessed_mne_v2.py

The new viewer script supports all file types:

```python
# View all files for a subject/session
DATA_PATH = "/Volumes/cenir/analyse/meeg/CYBERSART/BIDS/derivatives"
SUBJECT_ID = "05"
SART_SESSION = "Sart1"
FILE_TYPE = None  # Show all
EPOCH_TYPE = None  # Show all epochs

# View only raw files
FILE_TYPE = "raw"  # icaClean, csd, BrainVision

# View only ICA
FILE_TYPE = "ica"

# View only epochs
FILE_TYPE = "epochs"
EPOCH_TYPE = "evoked"  # or "state"

# View original BrainVision
DATA_PATH = "/Volumes/cenir/analyse/meeg/CYBERSART/BIDS/raw"
FILE_TYPE = "raw"
```

## Configuration File Reference

All naming conventions are defined in `config.yaml`:

```yaml
names:
  raw_clean_desc: icaClean  # ICA-cleaned raw
  csd_desc: csd             # CSD-transformed
  ica_desc: ica             # ICA object
  evoked_desc: evoked       # Evoked epochs
  state_desc: state         # State epochs
```

To change file naming, modify these values in `config.yaml` before running the pipeline.
