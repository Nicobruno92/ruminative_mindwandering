# Pipeline Review Report

**Date**: 2026-06-05
**Pipeline**: `/network/iss/levy/analyze/valerocabre/analyse/nbruno/depressed_mindwandering/mw_classification_pipeline/loso_pipeline/`
**Scientific Question**: Does EEG encoding of mind-wandering depend on which probe dimension is measured, and is that encoding strong enough for cross-subject (LOSO) trial-level prediction? Specifically: do AUC values follow the hierarchy onoff > content dimensions, and is the decodability of each dimension supported by a well-calibrated permutation null?
**Expected Direction**: All contrasts: mean AUC > 0.5, empirical p < 0.05. Hierarchy: onoff AUC highest; time AUC closest to 0.5. LOSO AUC lower than within-subject AUC, quantifying the idiosyncratic component.
**Prior Reviews**: None. This is the first review of this pipeline.

---

## Executive Summary

- **The pipeline is methodologically sound in its core design**: LOSO with within-subject scaling, MRMR feature selection refitted per fold, within-subject SMOTE, and a 500-permutation within-subject null constitute a serious, leakage-resistant approach. The key finding — that onoff is robustly decodable (AUC=0.630, p=0.002) while temporal orientation is not (AUC=0.508, p=0.423) — is credible and scientifically interpretable.

- **One confirmed statistical issue with moderate methodological impact**: the missing-value imputation uses the full-dataset per-subject mean rather than train-fold-only mean. This occurs before the CV split and constitutes a mild within-subject leakage path — unlikely to inflate AUC substantially, but it violates strict CV correctness and should be noted in the paper.

- **The on-disk results predate three code fixes**: the `raw_score_col` column labelling fix, the switch from median to mean imputation, and the density zero-fill. Results are therefore partially out of sync with the current codebase.

- **Feature importance reporting is based on a single run** rather than the aggregated 100-run mean — a presentation issue that inflates uncertainty in the feature importance panel.

- **The actual decodability hierarchy (LOSO) differs from the pre-stated expected hierarchy**: the observed order is onoff > confidence > selfother > valence > time, whereas the stated expectation was onoff > valence > selfother > confidence > time. This requires explicit discussion in the paper to avoid HARKing.

**Overall Scientific Quality**: Good — core methodology is defensible; two medium-severity issues and several missing analyses.

**Key Risk**: Results on disk were generated by an earlier code version (pre-audit); exact reproducibility from the saved config is uncertain. This must be resolved before publication.

## 1. Pipeline Overview

### Stage 1: Data Loading — `data_utils.py::prepare_data_for_contrast`

- **Input**: Aggregated probe-level CSV files in `/network/iss/cenir/analyse/meeg/CYBERSART/BIDS/features/sub-XX/eeg/junifer_aggregated/`. Two epoch types for the "all" family: `sleep` (slow waves, spindles) and `evoked` (ERPs, PSD, PE, wSMI, KoC, SEF).
- **What it does**: Loads all subjects x 4 tasks, concatenates long-format data, pivots to wide format (one row per probe), applies the label contrast (within-subject median split with gap=5), filters participants by minimum sample count (10) and minimum minority ratio (0.2), then resolves missing values.
- **Output**: `(df_prepared, X, y, groups, feature_cols)` — one row per surviving probe; 410 features for the "all" family.
- **Key decisions**:
  - Within-subject median split with a +/-5 neutral zone: probes within 5 points of the subject's personal median are excluded.
  - `min_samples=10`, `min_minority_ratio=0.2`: subjects with fewer than 10 post-gap probes or minority class < 20% are excluded per contrast. Different subjects survive across contrasts — N varies from 24 (confidence) to 32 (selfother).
  - Missing value handling: (1) zero-fill "density" columns (event rate = no event = true zero), (2) drop columns with >25% NaN fraction, (3) fill residual NaN with per-subject mean (global mean fallback).
  - **CRITICAL**: The imputation is applied to the full dataset before CV splitting. The per-subject mean is computed across all probes including those forming the future test fold.
- **Scientific assumptions**: Within-subject median split creates balanced binary labels by construction; the null AUC under random classification is mechanically 0.5 per subject, which is the correct reference point for LOSO.

### Stage 2: Feature Filtering — `run_loso_classification.py::filter_features_by_family`

- **Input**: Full 410-feature matrix.
- **What it does**: For the "all" family, `prefixes=null` — all 410 columns pass through. The feature set includes absolute PSD bands (delta through jota), relative PSD, PE (permutation entropy) across bands, Kolmogorov complexity, wSMI, SEF90/95, MSF, ERP components (N1, P1, P2, P3a, P3b), and sleep markers (slow wave density/duration/frequency/PTP/slope, spindle density) — for each ROI and aggregation statistic (trimmean and std).

### Stage 3: LOSO Classification — `analysis_utils.py::run_distribution_analysis`

- **Input**: X (410 features), y (binary), groups (subject IDs).
- **What it does**: Runs 100 passes of LOSO classification, each with a different random seed drawn from a global RNG (seed=42). In each pass, `run_model_pipeline_cv` is called with `LeaveOneGroupOut` CV. For each fold (one subject held out):
  1. Within-subject z-score scaling on train set; test subject scaled by their own mean/std independently.
  2. Within-subject SMOTE applied to training set (each subject oversampled independently to balance classes).
  3. MRMR feature selection on the oversampled training set — selects k=20 features.
  4. Random Forest classifier (200 trees, max_depth=8, balanced_subsample class weighting).
  5. Prediction on held-out subject; AUC, AUPRC, MCC, balanced accuracy computed.
- **Key scientific correctness checks**:
  - Scaling applied before SMOTE: correct.
  - Test subject scaled by their own stats: scientifically sound — no label information is used.
  - Subject leakage check in `_process_cv_fold_loso` line 953: raises ValueError if train/test subjects overlap — confirmed present.
  - All 100 seeds pre-generated from a single global RNG — SLURM jobs produce bit-identical results.

### Stage 4: Permutation Testing — `analysis_utils.py::run_permutation_distribution_analysis`

- **Input**: Same X, y, groups as Stage 3; 100 true-run AUC values.
- **What it does**: 500 permutations, labels shuffled within-subject (preserves marginal class proportions per subject). Empirical p-value via Phipson & Smyth add-one formula: p = (1 + count(null >= true_mean)) / (1 + 500).
- **Null calibration**: Well-centred at 0.50 (mean=0.503, SD=0.028) for onoff; similar for all contrasts. Confirms proper calibration.
- **Permutation scope `within`**: Correct choice for within-subject design — destroys label-feature association while preserving class proportions.

### Stage 5: Merging — `merge_loso_results.py`

- Stacks 100 per-run CSVs and 500 per-perm CSVs, computes empirical p-values (add-one) and Mann-Whitney U tests, saves aggregated files. All expected output files verified present for all 5 contrasts.

### Stage 6: Plotting — `scripts/generate_pipeline_plots.py`

- Called via subprocess after permutation testing. Generates ridgeline distributions, SHAP beeswarm, ROC curves, confusion matrices, AUC vs. onoff dispersion scatter.

## 3. Scientific Issues

### [SCI-001] Global Missing-Value Imputation Before CV — Severity: MEDIUM

- **Type**: Leakage (mild, within-subject)
- **Location**: `data_utils.py::prepare_data_for_contrast`, lines 1120–1141; `handle_missing_features`, lines 793–806.
- **What**: The per-subject mean imputation is computed on the entire dataset before any CV splitting. When a test probe's feature value is missing, its imputed fill value reflects the mean computed over all of that subject's probes, including the test probe itself (a tautological dependency) and other test-fold probes.
- **Why it matters scientifically**: This is a within-subject leakage path. The test probe's feature value influences the imputation fill for other features in training. The bias operates through a scalar mean — not the label — so AUC inflation is expected to be small, but the pipeline cannot be described as strictly leakage-free.
- **Evidence**: `data_utils.py` line 1126 calls `handle_missing_features(X, groups, ...)` where X is the full dataset before the CV splitting that happens inside `run_model_pipeline_cv`.
- **Scientific proposal**: Move imputation inside each CV fold — fit the per-subject mean on training subjects only, then apply to the test subject using the global training-fold mean as fallback for features entirely missing in the test subject's training data.
- **Confidence**: CONFIRMED

### [SCI-002] Jota Band Dominance — Physiological Plausibility — Severity: MEDIUM

- **Type**: Interpretation risk
- **Location**: `rf_loso_100runs_feature_importances_data.csv`, ranks 1 and 2 (but see note: single-run only).
- **What**: The top-ranked and second-ranked features (by importance in run_0) are `psd_bands_jota_mean_frontal_right_trimmean` and `psd_bands_jota_mean_frontal_left_trimmean`. "Jota" is not a canonical EEG frequency band. If it refers to frequencies above 50 Hz, it overlaps with electromyographic (EMG/muscle) artifact ranges.
- **Why it matters scientifically**: High-frequency frontal power differences between on/off-task probes could reflect muscle artifact (increased alertness = increased scalp muscle tension) rather than neural signals. This would mean the classifier is partly decoding physiological arousal via artifact, not neural MW signatures.
- **Evidence**: Feature name `psd_bands_jota` appears with frontal distribution — the highest-risk scalp region for EMG artifact. The frequency bounds of "jota" are not defined in the reviewed files.
- **Scientific proposal**: Verify the jota band frequency range from the junifer markers configuration. If jota > 40 Hz, run a sensitivity classification excluding jota features and report the resulting AUC. If AUC remains significantly above chance without jota, the result is robust. If AUC drops substantially, artifact-control preprocessing is required.
- **Confidence**: POSSIBLE (depends on jota band definition, not inspected in reviewed files)

### [SCI-003] LOSO Hierarchy Differs from Pre-Stated Expected Hierarchy — Severity: LOW

- **Type**: Interpretation issue / potential HARKing risk
- **Location**: CLAUDE.md narrative vs. actual results.
- **What**: CLAUDE.md (written as a project guide) lists the expected hierarchy as onoff > valence > selfother > confidence > time, with specific AUC values. The actual LOSO results show: onoff (0.630, p=0.002) > confidence (0.591, p=0.008) > selfother (0.562, p=0.016) > valence (0.547, p=0.078, NS) > time (0.508, p=0.423, NS).
- **Why it matters scientifically**: Confidence ranks second (not fourth), and valence is non-significant (not second). The CLAUDE.md AUC values appear to be within-subject values — the LOSO and within-subject hierarchies genuinely differ. This distinction must be stated explicitly; not doing so would constitute post-hoc adjustment of expectations.
- **Scientific proposal**: Report the two hierarchies separately. The LOSO hierarchy reflects generalizability across subjects; the within-subject hierarchy reflects subject-specific decodability. A dissociation between them is itself scientifically interesting and has a plausible interpretation: confidence may be encoded in a more subject-invariant way than emotional valence.
- **Confidence**: CONFIRMED

### [SCI-004] On-Disk Results Predate Code Fixes — Severity: MEDIUM

- **Type**: Inconsistency (code-results mismatch)
- **Location**: All result directories; current codebase.
- **What**: CLAUDE.md documents that three code fixes postdate the on-disk results: (1) `raw_score_col` now uses `label_source` instead of always "onoff" — for content dimensions, sample_predictions.csv files label the continuous score column as "onoff" instead of "valence", "selfother", etc.; (2) imputation switched from median to mean; (3) density zero-fill was added.
- **Why it matters**: For the onoff contrast, the `raw_score_col` fix is a no-op. For content dimension contrasts, the saved sample_predictions.csv files use incorrect column names for the continuous scores, making downstream re-analysis of prediction errors by score level incorrect. The imputation change and density zero-fill may alter feature matrices slightly, with unknown but likely small effects on AUC.
- **Scientific proposal**: Re-run all five contrasts with the current codebase before finalizing results. Compare group-level AUC values to two decimal places; if they agree, the reported values can stand with a code version footnote documenting the pre-fix pipeline.
- **Confidence**: CONFIRMED

### [SCI-005] Feature Importance Aggregation Missing — Severity: LOW

- **Type**: Incomplete reporting
- **Location**: `rf_loso_100runs_feature_importances_data.csv` (std column all zeros).
- **What**: The main feature importance CSV has std_importance=0 for all features, indicating it comes from a single run (run_0) rather than the 100-run aggregate. The 100-run importance data exists in `rf_loso_100runs_runs_summary.csv` (importance columns per run) but has not been aggregated into a mean+/-SD summary.
- **Scientific proposal**: Compute column-wise mean and SD of all `importance_*` columns in `rf_loso_100runs_runs_summary.csv` across 100 runs. Report features sorted by mean importance with cross-run SD bars. A feature with low across-run SD is robustly selected; one with high SD is opportunistically selected.
- **Confidence**: CONFIRMED

### [SCI-006] Per-Subject Permutation p-values Without Multiple Comparison Correction — Severity: LOW

- **Type**: Statistical error (missing correction)
- **Location**: `plots/rf_loso_subject_ridgelines_auc_pvalues.csv`.
- **What**: Per-subject significance is assessed at p<0.05 uncorrected across 29 tests (29 subjects), expecting ~1.45 false positives under the null.
- **Scientific proposal**: Apply Benjamini-Hochberg FDR correction at q=0.05 across all per-subject p-values within each contrast. Report both uncorrected and corrected counts. This is particularly important for the paper's claims about how many subjects are "individually decodable."
- **Confidence**: CONFIRMED

### [SCI-007] SMOTE Applied Before MRMR Feature Selection — Severity: LOW

- **Type**: Methodological concern
- **Location**: `ml_utils.py::_process_cv_fold_loso`, lines 976–988; pipeline order in `build_model_pipeline`.
- **What**: Within-subject SMOTE oversamples the training set; MRMR then selects features based on the SMOTE-expanded data. Synthetic samples are interpolations within training classes. MRMR may select features that distinguish interpolation endpoints rather than genuine class signal.
- **Why it matters**: Both true and permuted runs use the same order (SMOTE then MRMR), so the permutation p-value comparison is internally consistent — relative inflation cancels out. The absolute AUC may be slightly inflated. This is a known issue in the imbalanced learning literature.
- **Scientific proposal**: Consider applying MRMR to the real (pre-SMOTE) training data only, then applying SMOTE to the MRMR-reduced feature space. This avoids feature selection being influenced by synthetic samples. Alternatively, accept the current order but note it as a limitation and verify via the Type I error simulation (M6).
- **Confidence**: POSSIBLE (effect magnitude uncertain; internally consistent for permutation p-values)

## 5. Scientific Proposals

### For SCI-001: Move Imputation Inside CV

Restructure the pipeline so that imputation is fitted on the training fold and applied to the test fold. Specifically: compute the per-subject mean for each feature using only training subjects' data; for the held-out test subject, their training-fold data is empty (LOSO), so use the global training-fold mean as fallback. This is standard practice in clinical prediction modelling and eliminates the within-subject leakage path without affecting MRMR or SMOTE logic.

### For SCI-002: Verify and Isolate the Jota Band

Determine the exact frequency range of the "jota" band from the junifer markers pipeline configuration (likely in `junifer_markers/*/config.yaml`). If jota exceeds 40 Hz, run a sensitivity classification excluding jota and, if warranted, gamma-band features. If AUC without jota remains significantly above chance, the result is robust. If AUC drops substantially, add EMG artifact control (ICA-based muscle component removal, or high-frequency channel interpolation) to the preprocessing pipeline.

### For SCI-003: Distinguish Within-Subject and LOSO Hierarchies

Report the two hierarchies separately in the paper. The LOSO hierarchy (onoff > confidence > selfother > valence > time) reflects generalizability of neural signatures across subjects. The within-subject hierarchy (onoff > valence > confidence > selfother > time, based on CLAUDE.md values) reflects subject-specific decodability including idiosyncratic components. A dissociation between the two is scientifically meaningful: it would show that confidence is encoded in a more subject-invariant way than emotional valence, which could be interpreted in terms of arousal (confidence) vs. affective content (valence) neural generators.

### For SCI-004: Re-run with Current Codebase

Before finalizing results, execute a complete re-run of all five contrasts using the current codebase. The primary concern is the `raw_score_col` fix for content dimensions (affects metadata in sample_predictions.csv, not the AUC computation itself), the imputation method change, and the density zero-fill. A sensitivity check comparing group-level AUC from old and new runs to two decimal places would determine whether the reported results can stand with a version footnote.

### For Missing Analysis M1: Aggregate Feature Importances (No Rerunning Required)

Compute column-wise mean and SD of all `importance_*` columns in `rf_loso_100runs_runs_summary.csv` across the 100 rows (one per true run). This is a post-processing step on existing data. Features with mean importance > 0 in fewer than 20% of runs are effectively noise-selected and should be excluded from the narrative. Features with low cross-run SD are the robustly informative ones to report.

### For Missing Analysis M5: Off-Task-Restricted Content Classification

Submit SLURM jobs for the commented-out `_offtask` contrast variants already defined in config.yaml. This tests whether content dimensions (valence, selfother, time) are EEG-decodable specifically during MW episodes (off-task probes only). This analysis is scientifically important because content dimensions are conceptually meaningful only during MW; if they are decodable also during on-task periods, it would suggest the classifier is picking up on task-correlated content patterns rather than MW content per se.

### For Missing Analysis M6: Type I Error Simulation

Run the Type I error simulation using `type1_error/run_type1_error_loso.py`. Under the null, the pipeline's empirical p-value should follow U[0,1] and the FPR at alpha=0.05 should equal 0.05. Inflation above 0.10 would indicate anti-conservative behaviour in the permutation test, likely due to SMOTE-then-MRMR ordering. This result should be reported in the paper's methods validation section.

## 8. Overall Assessment

**What this pipeline found**: Cross-subject LOSO decoding of on/off-task EEG state is significantly above chance (AUC=0.630, p=0.002, n=29 subjects), with 25/29 subjects above individual chance and 8–10 individually significant (uncorrected). The decodability hierarchy across probe dimensions is: onoff (p=0.002) > confidence (p=0.008) > selfother (p=0.016) > valence (not significant, p=0.078) > time (at chance, p=0.423). The top predictive features are frontal PSD in beta, gamma, and jota bands plus alpha permutation entropy. Sleep markers (slow waves, spindles) receive near-zero importance, suggesting the within-SART task EEG is dominated by frequency-domain signatures rather than sleep-like transients.

**Confidence in findings**: Medium-High for the primary finding (onoff decodability); Medium for the content dimension hierarchy. The core onoff result is robust and unlikely to change qualitatively with the identified fixes. The content dimension hierarchy is exploratory and the exact rank ordering (especially confidence vs. selfother vs. valence) should be treated with caution. Results on disk may not perfectly reflect the current codebase, adding uncertainty to be resolved before publication.

**Biggest threats to validity** (ranked):
1. On-disk results predate code fixes — exact reproducibility from current code is unverified (medium impact, requires rerun to resolve)
2. Global imputation before CV — mild within-subject leakage path (small impact on AUC, medium impact on methodological rigor claim)
3. Jota band dominance — if jota > 40 Hz, top features may reflect muscle artifact (unknown impact, requires frequency verification)
4. LOSO hierarchy differs from stated expectation — must be clearly distinguished from within-subject hierarchy to avoid HARKing (interpretive)
5. Per-subject significance uncorrected — ~1–2 false positives expected among 8–10 reported (minor)

**Recommended next steps**:
1. Re-run all five contrasts with the current codebase (resolves SCI-004). Verify group-level AUC agrees to two decimal places with reported values.
2. Verify the frequency range of the jota band; run sensitivity analysis excluding high-frequency features if jota > 40 Hz (SCI-002 / M2).
